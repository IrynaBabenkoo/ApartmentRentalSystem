Система оренди житла

Пошук житла

Пошук, бронювання, додаткові послуги, відгуки та бонусний рахунок у єдиному клієнтському інтерфейсі.

Пошук і фільтрація житла

Пошук виконується через метод отримання списку апартаментів із параметрами фільтрації.

Перевірка доступності

Вкажіть ID апартаменту для перегляду заброньованих періодів.

Тут буде відображено інформацію про доступність апартаменту.
Список апартаментів

Картки формуються на основі відповіді методу `GET /api/Apartments`.

Створення бронювання

Орендар може створити бронювання для вибраного апартаменту.

Оплата бронювання

Після вибору бронювання можна виконати оплату та отримати бали лояльності.

Мої бронювання

Список формується через метод `GET /api/Reservations/guest/{guestId}`.
